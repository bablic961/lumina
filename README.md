# ✦ Lumina

**Свет в каждом сообщении.**

Веб-мессенджер на Next.js 14: личные чаты, группы, каналы, звонки, истории
и сквозное шифрование — в интерфейсе из светящегося стекла.

</div>

---

## Быстрый старт

```bash
npm install
cp .env.example .env      # заполнять ничего не обязательно — см. «Переменные»
npm run setup             # prisma generate + db push + seed
npm run dev               # http://localhost:3000
```

Демо-аккаунты после сида (пароль у всех — `lumina`):

| Логин | Кто |
| --- | --- |
| `nova@lumina.app` | обычный пользователь, вокруг него построены все демо-чаты |
| `admin@lumina.app` | администратор, видит `/app/admin` |
| `orion@ / vega@ / lyra@ / atlas@lumina.app` | собеседники |

## Стек

- **Next.js 14.2.35** (App Router) + TypeScript + Tailwind CSS
- **Prisma 5.12** + SQLite по умолчанию (схема портируема на PostgreSQL — см. ниже)
- **Socket.io 4.7** в кастомном сервере `server.js` — реальное время и WebRTC-сигналинг
- **NextAuth 4.24** — credentials + OAuth (Google, GitHub, Discord, Apple)
- **Zustand** (UI-состояние, тосты, лайтбокс) + **React Query 5** (серверные данные)
- **Web Crypto API** — E2E для личных чатов и зашифрованные заметки
- **web-push** — уведомления через service worker

## Переменные окружения

Обязательные — только первые четыре; всё остальное **деградирует мягко**:
интеграция без ключа просто отвечает «не настроено», OAuth-провайдер без
`CLIENT_ID` не появляется на странице входа, push без VAPID остаётся в приложении.

```ini
DATABASE_URL="file:./dev.db"      # или postgresql://…
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="…"               # openssl rand -base64 32
PORT=3000
```

Опционально: `GOOGLE_*`, `GITHUB_*`, `DISCORD_*`, `APPLE_*`, `STORAGE_DRIVER`
(`local` | `blob`), `BLOB_READ_WRITE_TOKEN`, `MAX_UPLOAD_MB`,
`OPENWEATHER_API_KEY`, `GIPHY_API_KEY`, `ANTHROPIC_API_KEY` + `ANTHROPIC_MODEL`,
`VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT`
(`npx web-push generate-vapid-keys`), `SMTP_*`.

## Переезд на PostgreSQL

Схема специально написана без провайдер-специфичных штук: нет нативных enum
(статусы — `String` + union-типы в `src/types`), нет `Json`-колонок (JSON лежит
строками), нет `@db.*`. Достаточно поменять `provider` в `prisma/schema.prisma`
и `DATABASE_URL`, затем `npx prisma migrate dev`. Единственное, что стоит
добавить вручную — `mode: 'insensitive'` в поиске (`src/app/api/search/route.ts`):
в SQLite `contains` уже регистронезависим для ASCII, в Postgres нет.

## Что реализовано

**Аутентификация и профили** — email + пароль (bcrypt), OAuth-кнопки для четырёх
провайдеров, `@username`, био, статус-эмодзи с текстом, presence
(онлайн / отошёл / не беспокоить / невидимый), верификация, дни рождения,
бейджи, приватность «кто может писать», скрытие presence и галочек прочтения.

**Чаты и сообщения** — DM, группы, каналы; realtime через Socket.io; ✓/✓✓;
редактирование с пометкой «изменено»; удаление у себя и у всех; ответы,
пересылки, закрепления; реакции; голосовые с волновой формой; файлы; подсветка
кода; геопозиция; черновики; бесконечный скролл; самоуничтожение (5 с — неделя);
поиск по сообщениям с фильтрами; слэш-команды и командная палитра (`Ctrl/⌘ + K`).

**Медиа** — лайтбокс с зумом и поворотом, галерея чата, `sharp`-оптимизация
картинок при загрузке, drag & drop, плеер голосовых на wavesurfer.

**Звонки** — WebRTC 1:1 и групповые (mesh), демонстрация экрана, размытие фона
на Canvas2D, индикатор качества, чат внутри звонка. Запись — с подтверждением и
оповещением участников, файл сохраняется только на устройстве.

**Группы и каналы** — роли OWNER / ADMIN / MODERATOR / MEMBER плюс кастомные
роли с наборами прав, инвайт-ссылки с TTL и лимитом использований, «только
админы пишут», slow mode, опросы (в т.ч. мультивыбор), упоминания и `@all`.

**Оформление** — светлая / тёмная / AMOLED / авто, 12 акцентных градиентов,
три плотности, масштаб шрифта, обои чата (градиент-пресеты или загруженная
картинка), фокус-режим.

**Безопасность** — 2FA по TOTP (без внешних зависимостей, `src/lib/totp.ts`),
список устройств с отзывом, блокировки, жалобы, E2E для личных чатов на Web
Crypto (ECDH P-256 + AES-GCM), зашифрованные заметки `/app/notes`, slow mode.

**Соцфункции** — истории на 24 часа с реакциями и списком просмотров,
статусы, подарки, бейджи, «сохранённые», папки чатов, архив.

**Админка** — статистика с графиком за 14 дней, пользователи (верификация,
права, баны), очередь жалоб, менеджер стикер-паков, rate limits, рассылки,
журнал аудита.

**PWA** — манифест с шорткатами, service worker (push, offline-фолбэк,
кеш статики и загрузок), страница `/offline`, иконки включая maskable.

**Интеграции** — OpenWeatherMap (`/weather`), переводчик, Giphy, калькулятор
через `=`, AI-ассистент `@lumina` на Anthropic SDK. Каждая без ключа отвечает
понятной ошибкой, а не падает.

**i18n** — 10 локалей (ru, en, es, de, fr, zh, ja, ko, ar, he), RTL для арабского
и иврита через логические CSS-свойства.

## Что оставлено заглушкой

Честный список — эти вещи есть в схеме и/или интерфейсе, но не доведены:

- **OCR по картинкам.** `Attachment.ocrText` принимается API и показывается в
  UI, но клиент его не заполняет: `tesseract.js` установлен и не подключён.
- **Отправка писем.** `SMTP_*` читаются, но подтверждение email и сброс пароля
  через письмо не реализованы — регистрация сразу активна.
- **Загрузка в S3/Vercel Blob.** `STORAGE_DRIVER=blob` описан, рабочий путь —
  локальный диск (`public/uploads`).
- **Календарь, Figma, Spotify, GitHub, YouTube, Twitter/X** из списка интеграций:
  ссылки разворачиваются в превью средствами `RichText`, отдельных API-клиентов нет.
- **Биометрия** (WebAuthn) — не реализована; 2FA закрывает тот же сценарий.
- **Совместные плейлисты, комнаты ожидания, «сейчас слушаю»** — в схеме нет
  соответствующих моделей.
- **Push без VAPID-ключей** не уходит: `server/push.js` тихо выключается.
- **Rate limits** реально применяются только к `integrations.ai`; остальные
  четыре ключа настраиваются в админке, но счётчик по ним пока не списывается.
- **`Attachment.blurhash`** есть в схеме и DTO, но не вычисляется при загрузке.
- **`CallSession.recordingUrl`** не заполняется — запись остаётся на устройстве.

## Осознанные отклонения от изначальной спецификации

| В спеке | В проекте | Почему |
| --- | --- | --- |
| PostgreSQL | SQLite (провайдер меняется одной строкой) | запуск без инфраструктуры; схема портируема |
| `next@14.2.3`, `zod@3.22.4` и др. версии из списка | подняты до `next@14.2.35`, `zod@3.25.76`, `next-auth@4.24.15`, `socket.io@4.8.3`, `sharp@0.35.4`, `axios@1.20.0`, `nodemailer@7.0.10`, `tsx@4.23.13` | закрытые CVE в исходных версиях |
| `multer` | нативный разбор `FormData` в route handler | в App Router middleware-парсер не нужен |
| `simple-peer` | свой хук `useWebRTC` на `RTCPeerConnection` | `simple-peer` тянет полифилы Node и давно без релизов |
| `react-window` для списка сообщений | CSS `content-visibility: auto` | сохраняет нативный скролл, «прыгающие» позиции и `Ctrl+F`; без «окна» проще закреплённые и системные сообщения |
| MediaPipe для виртуального фона | размытие на Canvas2D | MediaPipe — это +20 МБ WASM ради демо-функции |
| SWR | `@tanstack/react-query` | нужны `useInfiniteQuery` и инвалидация по ключам |
| Отдельный WS-сервер | Socket.io внутри `server.js` | один порт, одна сессия, один PrismaClient |
| Redis для rate limit | таблица `RateLimitRule` + счётчики в памяти | без внешнего сервиса; лимиты правятся из админки |

Ещё несколько мест, где реализация отличается сознательно:

- **Enum'ы** живут как `String` в базе и union-типы в `src/types` — иначе схема
  перестала бы быть переносимой между SQLite и Postgres.
- **QR-код для 2FA** не рисуется: показывается base32-секрет с кнопкой копирования
  и ссылка `otpauth://`, которую приложение-аутентификатор открывает само.
  Так не пришлось тащить генератор QR ради одного экрана.
- **Звуки уведомлений** синтезируются Web Audio API (`src/lib/sound.ts`),
  а не лежат файлами.
- **Стикеры и фоны историй** — сгенерированные SVG в `public/`, чтобы демо-данные
  не зависели от сети.
- **Установленные, но не задействованные пакеты** из списка спецификации:
  `axios`, `jsonwebtoken`, `nodemailer`, `react-dropzone`, `react-markdown`,
  `date-fns`, `webrtc-adapter`, `react-window`, `tesseract.js`. Оставлены, чтобы
  не расходиться со спекой; их можно удалить одной командой.

## Известные шероховатости

- `npm audit`: было 18 находок (1 critical, 11 high), осталось **7 high**. Закрыты
  все, что лечатся без мажорного апгрейда: `next-auth` (critical, подмена домена
  в email-провайдере), `socket.io` + `socket.io-client` (истощение соединений в
  engine.io, утечка памяти в `ws`), `sharp` (CVE в libvips — единственная из них,
  которая реально трогает пользовательский ввод), `axios`, `tsx`/`esbuild`.
  Остались только те, где `fixAvailable` — мажор: `next@16` (DoS в оптимизаторе
  картинок; проект не использует `next/image` вообще), `postcss` и
  `eslint-config-next` (тянутся тем же мажором `next`), `nodemailer@10`
  (установлен, но нигде не импортируется). `npm audit fix --force` не применялся:
  он тащит Next 16, а это отдельная миграция.
- SQLite и групповые звонки на 100 участников — вещи из разных весовых
  категорий: mesh-топология упрётся в клиента задолго до базы. Для реальной
  нагрузки нужен SFU (mediasoup / LiveKit).
- Первый заход на `/app` в dev-режиме компилируется ~6 секунд — это Next dev,
  в production-сборке страницы отдаются за десятки миллисекунд.
